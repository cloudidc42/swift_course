# Part 80: Swift Macros

## บทนำ

Swift Macros เป็นฟีเจอร์ที่แนะนำใน Swift 5.9 (Xcode 15) ที่ช่วยให้เราสามารถสร้าง code ที่ถูก generate ณ compile time ได้ Macros ช่วยลดการเขียน boilerplate code และทำให้ code อ่านง่ายขึ้น ในบทนี้เราจะเรียนรู้ทุกแง่มุมของ Swift Macros ตั้งแต่ concept พื้นฐานไปจนถึงการสร้าง macro library ของตัวเอง

---

## 1. What Are Swift Macros?

Macros คือ programs ที่ run ณ compile time เพื่อ transform code Swift Macros ต่างจาก macros ใน C/C++ ตรงที่:

1. **Type-safe**: ทำงานกับ AST (Abstract Syntax Tree) ไม่ใช่ text substitution
2. **Hygienic**: ไม่สามารถ accidentally capture variables จาก surrounding scope
3. **Transparent**: สามารถดูผลลัพธ์ได้ใน Xcode

```swift
// ก่อนใช้ Macros: เขียน boilerplate เยอะ
struct Point {
    var x: Double
    var y: Double
    
    // ต้องเขียน CodingKeys, encode, decode เอง
    enum CodingKeys: String, CodingKey {
        case x, y
    }
}

// หลังใช้ Macros: สะอาดกว่ามาก
@CodingKeys
struct PointWithMacro {
    var x: Double
    var y: Double
    // Macro generate code ให้อัตโนมัติ
}

// Built-in macro ตัวอย่าง
let x = 5
let y = 7
let result = #stringify(x + y)
// result เป็น ("x + y", 12) - tuple ของ expression string และค่า
```

### 1.1 ทำไมต้องใช้ Macros?

```swift
// ปัญหา: Code ซ้ำซ้อนที่ต้องเขียนทุกครั้ง

// สมมติ: ต้องการ enum ที่มี string representation
enum Direction: String {
    case north = "North"
    case south = "South"
    case east = "East"
    case west = "West"
}

// กับ Macros:
@StringEnum
enum DirectionWithMacro {
    case north, south, east, west
    // Macro เพิ่ม string representation ให้อัตโนมัติ
}

// ประโยชน์ของ Macros:
// 1. ลด boilerplate code
// 2. หลีกเลี่ยง error ที่เกิดจากการเขียน code ซ้ำ
// 3. Compiler ตรวจสอบ correctness ให้
// 4. IDE support (autocomplete, syntax highlighting)
```

## 2. Macros vs Code Generation

### 2.1 เปรียบเทียบ Approaches

```swift
// Approach 1: Code Generation (Sourcery, SwiftGen)
// - Generate .swift files ณ build time
// - Files อยู่ใน repository
// - ต้อง run script ก่อน build
// - ยากต่อการ debug
// - Output มองเห็นชัดเจน

// Generated file ตัวอย่าง:
// Auto-generated by Sourcery
// extension User: Equatable {
//     static func == (lhs: User, rhs: User) -> Bool {
//         return lhs.id == rhs.id && lhs.name == rhs.name
//     }
// }

// Approach 2: Swift Macros
// - Generate code ณ compile time
// - ไม่มี generated files ใน repository
// - ทำงานอัตโนมัติเมื่อ compile
// - Debug ได้ใน Xcode
// - Output ดูได้โดย expand macro ใน Xcode

@Equatable
struct User {
    let id: Int
    let name: String
    // Macro generate Equatable conformance ให้
}
```

## 3. ประเภทของ Macros

### 3.1 Freestanding Macros (#)

Freestanding macros ใช้ `#` prefix และสามารถใช้ได้ที่ expression หรือ declaration level

```swift
// Expression Macros - return ค่า
let value = #stringify(1 + 2)
// Expands to: ("1 + 2", 3)

let line = #line        // บรรทัดปัจจุบัน
let column = #column    // column ปัจจุบัน
let file = #file        // ชื่อไฟล์ปัจจุบัน
let function = #function // ชื่อฟังก์ชันปัจจุบัน

// Declaration Macros - สร้าง declarations
#externalMacro(module: "MyMacros", type: "MyMacro")
```

### 3.2 Attached Macros (@)

Attached macros ใช้ `@` prefix และแนบกับ declaration

```swift
// @Observable - built-in macro ใน SwiftUI
import Observation

@Observable
class Person {
    var name: String = ""
    var age: Int = 0
}
// Macro generate code สำหรับ observation

// @Bindable
struct PersonEditor: View {
    @Bindable var person: Person
    
    var body: some View {
        TextField("Name", text: $person.name)
        Stepper("Age: \(person.age)", value: $person.age)
    }
}
```

## 5. SwiftSyntax Library

SwiftSyntax เป็น library ที่ใช้สำหรับ parsing และ manipulating Swift source code

### 5.1 AST พื้นฐาน

```swift
// SwiftSyntax แสดง Swift code เป็น tree structure

// Source code: func add(a: Int, b: Int) -> Int { a + b }
// AST:
// FunctionDeclSyntax
//   ├── FunctionSignatureSyntax
//   │   ├── ParameterList: [FunctionParameterSyntax(a: Int), FunctionParameterSyntax(b: Int)]
//   │   └── ReturnType: Int
//   └── CodeBlockSyntax
//       └── ReturnStmtSyntax: a + b

import SwiftSyntax
import SwiftSyntaxBuilder

// การสร้าง Syntax Node
func createFunctionDecl() -> DeclSyntax {
    """
    func greet(name: String) -> String {
        return "Hello, \\(name)!"
    }
    """
}

// การ traverse AST
class FunctionFinder: SyntaxVisitor {
    var functionNames: [String] = []
    
    override func visit(_ node: FunctionDeclSyntax) -> SyntaxVisitorContinueKind {
        functionNames.append(node.name.text)
        return .visitChildren
    }
}
```

### 5.2 Syntax Manipulation

```swift
import SwiftSyntax
import SwiftSyntaxBuilder

// การแก้ไข syntax tree
class FunctionRenamer: SyntaxRewriter {
    let oldName: String
    let newName: String
    
    init(from oldName: String, to newName: String) {
        self.oldName = oldName
        self.newName = newName
    }
    
    override func visit(_ node: FunctionDeclSyntax) -> DeclSyntax {
        guard node.name.text == oldName else {
            return super.visit(node)
        }
        
        return super.visit(node.with(\.name, .identifier(newName)))
    }
}

// การสร้าง syntax จาก scratch
func makeVariableDecl(name: String, type: String, value: String) -> VariableDeclSyntax {
    VariableDeclSyntax(
        bindingSpecifier: .keyword(.var)
    ) {
        PatternBindingSyntax(
            pattern: IdentifierPatternSyntax(identifier: .identifier(name)),
            typeAnnotation: TypeAnnotationSyntax(
                type: IdentifierTypeSyntax(name: .identifier(type))
            ),
            initializer: InitializerClauseSyntax(
                value: ExprSyntax(stringLiteral: value)
            )
        )
    }
}
```

## 7. ExpressionMacro

Expression macros สามารถใช้ได้ที่ expression position และ return expression ใหม่

### 7.1 #stringify Macro

```swift
import SwiftSyntax
import SwiftSyntaxMacros
import SwiftSyntaxBuilder

// Declaration ใน public API
public macro stringify<T>(_ value: T) -> (T, String) = 
    #externalMacro(module: "MyMacrosImplementation", type: "StringifyMacro")

// Implementation
public struct StringifyMacro: ExpressionMacro {
    public static func expansion(
        of node: some FreestandingMacroExpansionSyntax,
        in context: some MacroExpansionContext
    ) throws -> ExprSyntax {
        guard let argument = node.arguments.first?.expression else {
            throw MacroError.missingArgument
        }
        
        // Wrap expression ใน tuple กับ string representation
        return "(\(argument), \"\(argument)\")"
    }
}

enum MacroError: Error, CustomStringConvertible {
    case missingArgument
    case invalidArgument(String)
    
    var description: String {
        switch self {
        case .missingArgument:
            return "Missing required argument"
        case .invalidArgument(let msg):
            return "Invalid argument: \(msg)"
        }
    }
}

// การใช้งาน
let result = #stringify(1 + 2)
// Expands to: (1 + 2, "1 + 2")
// result.0 == 3
// result.1 == "1 + 2"
```

### 7.2 #URL Macro - Type-safe URL creation

```swift
// Declaration
public macro URL(_ string: String) -> URL = 
    #externalMacro(module: "MyMacrosImplementation", type: "URLMacro")

// Implementation
public struct URLMacro: ExpressionMacro {
    public static func expansion(
        of node: some FreestandingMacroExpansionSyntax,
        in context: some MacroExpansionContext
    ) throws -> ExprSyntax {
        // ดึง string argument
        guard let argument = node.arguments.first?.expression,
              let stringLiteral = argument.as(StringLiteralExprSyntax.self),
              let stringValue = stringLiteral.representedLiteralValue else {
            throw MacroError.invalidArgument("Expected string literal")
        }
        
        // ตรวจสอบว่า URL valid ณ compile time
        guard URL(string: stringValue) != nil else {
            throw MacroError.invalidArgument("Invalid URL: \(stringValue)")
        }
        
        // Return force unwrap ที่ safe เพราะเรา validate แล้ว
        return "URL(string: \(argument))!"
    }
}

// การใช้งาน
let apiURL = #URL("https://api.example.com/users")
// Expands to: URL(string: "https://api.example.com/users")!
// Compile error ถ้า URL ไม่ valid:
// let badURL = #URL("not a url ://bad") // Error!
```

## 9. PeerMacro

Peer macros สร้าง declarations ใหม่ที่อยู่ใน same scope กับ declaration ที่แนบ

### 9.1 @AddAsync - เพิ่ม async version ให้ completion handler function

```swift
// Declaration
@attached(peer, names: overloaded)
public macro AddAsync() = 
    #externalMacro(module: "MyMacrosImplementation", type: "AddAsyncMacro")

// Implementation
import SwiftSyntax
import SwiftSyntaxMacros

public struct AddAsyncMacro: PeerMacro {
    public static func expansion(
        of node: AttributeSyntax,
        providingPeersOf declaration: some DeclSyntaxProtocol,
        in context: some MacroExpansionContext
    ) throws -> [DeclSyntax] {
        // ตรวจสอบว่าเป็น function declaration
        guard let funcDecl = declaration.as(FunctionDeclSyntax.self) else {
            throw MacroError.invalidArgument("@AddAsync can only be applied to functions")
        }
        
        // หา completion handler parameter
        let params = funcDecl.signature.parameterClause.parameters
        guard let lastParam = params.last,
              lastParam.type.description.contains("(") else {
            throw MacroError.invalidArgument("Last parameter must be a completion handler")
        }
        
        // สร้าง async version
        let asyncFunc: DeclSyntax = """
        func \(funcDecl.name)() async {
            await withCheckedContinuation { continuation in
                \(funcDecl.name) { result in
                    continuation.resume(returning: result)
                }
            }
        }
        """
        
        return [asyncFunc]
    }
}

// การใช้งาน
class NetworkManager {
    @AddAsync
    func fetchData(completion: @escaping (Data) -> Void) {
        // Original implementation
    }
    
    // Macro generates:
    // func fetchData() async -> Data {
    //     await withCheckedContinuation { continuation in
    //         fetchData { result in
    //             continuation.resume(returning: result)
    //         }
    //     }
    // }
}
```

## 10. MemberMacro

Member macros เพิ่ม members ให้กับ type

### 10.1 @Codable - Custom Codable Generation

```swift
// Declaration
@attached(member, names: named(init(from:)), named(encode(to:)), named(CodingKeys))
public macro Codable() = 
    #externalMacro(module: "MyMacrosImplementation", type: "CodableMacro")

// Implementation
public struct CodableMacro: MemberMacro {
    public static func expansion(
        of attribute: AttributeSyntax,
        providingMembersOf declaration: some DeclGroupSyntax,
        conformingTo protocols: [TypeSyntax],
        in context: some MacroExpansionContext
    ) throws -> [DeclSyntax] {
        // ดึง stored properties
        let properties = declaration.memberBlock.members
            .compactMap { $0.decl.as(VariableDeclSyntax.self) }
            .compactMap { varDecl -> (name: String, type: String)? in
                guard let binding = varDecl.bindings.first,
                      let pattern = binding.pattern.as(IdentifierPatternSyntax.self),
                      let typeAnnotation = binding.typeAnnotation else {
                    return nil
                }
                return (name: pattern.identifier.text, 
                        type: typeAnnotation.type.description.trimmingCharacters(in: .whitespaces))
            }
        
        // สร้าง CodingKeys enum
        let codingKeysMembers = properties.map { prop in
            "case \(prop.name)"
        }.joined(separator: "\n        ")
        
        let codingKeys: DeclSyntax = """
        enum CodingKeys: String, CodingKey {
            \(raw: codingKeysMembers)
        }
        """
        
        // สร้าง init(from decoder:)
        let initDecoderBody = properties.map { prop in
            "\(prop.name) = try container.decode(\(prop.type).self, forKey: .\(prop.name))"
        }.joined(separator: "\n        ")
        
        let initDecoder: DeclSyntax = """
        init(from decoder: Decoder) throws {
            let container = try decoder.container(keyedBy: CodingKeys.self)
            \(raw: initDecoderBody)
        }
        """
        
        // สร้าง encode(to encoder:)
        let encodeBody = properties.map { prop in
            "try container.encode(\(prop.name), forKey: .\(prop.name))"
        }.joined(separator: "\n        ")
        
        let encodeFunc: DeclSyntax = """
        func encode(to encoder: Encoder) throws {
            var container = encoder.container(keyedBy: CodingKeys.self)
            \(raw: encodeBody)
        }
        """
        
        return [codingKeys, initDecoder, encodeFunc]
    }
}

// การใช้งาน
@Codable
struct Product {
    var id: Int
    var name: String
    var price: Double
}

// Macro generates:
// enum CodingKeys: String, CodingKey {
//     case id, name, price
// }
// init(from decoder: Decoder) throws { ... }
// func encode(to encoder: Encoder) throws { ... }

let json = """
{"id": 1, "name": "Widget", "price": 9.99}
""".data(using: .utf8)!

let product = try JSONDecoder().decode(Product.self, from: json)
print(product.name) // "Widget"
```

## 11. AccessorMacro

Accessor macros เพิ่ม getter/setter ให้กับ property

### 11.1 @UserDefault - Property wrapper-like ด้วย Macro

```swift
// Declaration
@attached(accessor)
public macro UserDefault(key: String) = 
    #externalMacro(module: "MyMacrosImplementation", type: "UserDefaultMacro")

// Implementation
public struct UserDefaultMacro: AccessorMacro {
    public static func expansion(
        of node: AttributeSyntax,
        providingAccessorsOf declaration: some DeclSyntaxProtocol,
        in context: some MacroExpansionContext
    ) throws -> [AccessorDeclSyntax] {
        // ดึง key argument
        guard let keyArgument = node.arguments?.as(LabeledExprListSyntax.self)?.first,
              let keyLiteral = keyArgument.expression.as(StringLiteralExprSyntax.self),
              let key = keyLiteral.representedLiteralValue else {
            throw MacroError.missingArgument
        }
        
        // สร้าง getter
        let getter: AccessorDeclSyntax = """
        get {
            return UserDefaults.standard.object(forKey: "\(raw: key)") as? Value
        }
        """
        
        // สร้าง setter
        let setter: AccessorDeclSyntax = """
        set {
            UserDefaults.standard.set(newValue, forKey: "\(raw: key)")
        }
        """
        
        return [getter, setter]
    }
}

// การใช้งาน
struct AppSettings {
    @UserDefault(key: "user_name")
    var userName: String?
    
    @UserDefault(key: "is_dark_mode")
    var isDarkMode: Bool?
}

// Macro generates:
// var userName: String? {
//     get { UserDefaults.standard.object(forKey: "user_name") as? String }
//     set { UserDefaults.standard.set(newValue, forKey: "user_name") }
// }
```

## 13. ConformanceMacro

Conformance macros เพิ่ม protocol conformances

### 13.1 @AutoEquatable

```swift
// Declaration
@attached(conformance)
@attached(member, names: named(==))
public macro AutoEquatable() = 
    #externalMacro(module: "MyMacrosImplementation", type: "AutoEquatableMacro")

// Implementation (Combined conformance + member macro)
public struct AutoEquatableMacro: ConformanceMacro, MemberMacro {
    
    // ConformanceMacro: เพิ่ม Equatable conformance
    public static func expansion(
        of node: AttributeSyntax,
        providingConformancesOf declaration: some DeclGroupSyntax,
        in context: some MacroExpansionContext
    ) throws -> [(TypeSyntax, GenericWhereClauseSyntax?)] {
        return [("Equatable", nil)]
    }
    
    // MemberMacro: เพิ่ม == operator
    public static func expansion(
        of attribute: AttributeSyntax,
        providingMembersOf declaration: some DeclGroupSyntax,
        conformingTo protocols: [TypeSyntax],
        in context: some MacroExpansionContext
    ) throws -> [DeclSyntax] {
        // ดึง properties
        let properties = declaration.memberBlock.members
            .compactMap { $0.decl.as(VariableDeclSyntax.self) }
            .compactMap { $0.bindings.first?.pattern.as(IdentifierPatternSyntax.self)?.identifier.text }
        
        // สร้าง == operator
        let comparisons = properties.map { prop in
            "lhs.\(prop) == rhs.\(prop)"
        }.joined(separator: " && ")
        
        let equalityFunc: DeclSyntax = """
        static func == (lhs: Self, rhs: Self) -> Bool {
            return \(raw: comparisons)
        }
        """
        
        return [equalityFunc]
    }
}

// การใช้งาน
@AutoEquatable
struct Point {
    var x: Double
    var y: Double
}

// Macro generates Equatable conformance and:
// static func == (lhs: Point, rhs: Point) -> Bool {
//     return lhs.x == rhs.x && lhs.y == rhs.y
// }

let p1 = Point(x: 1.0, y: 2.0)
let p2 = Point(x: 1.0, y: 2.0)
print(p1 == p2) // true
```

### 18.1 Understanding @Observable

```swift
import Observation

// Source code:
@Observable
class BankAccount {
    var balance: Double = 0
    var owner: String = ""
    var transactions: [String] = []
}

// @Observable expands to (roughly):
class BankAccount {
    var balance: Double = 0 {
        @storageRestrictions(initializes: _balance)
        init(initialValue) {
            _balance = initialValue
        }
        get {
            access(keyPath: \.balance)
            return _balance
        }
        set {
            withMutation(keyPath: \.balance) {
                _balance = newValue
            }
        }
    }
    
    var _balance: Double = 0
    
    // Similar for owner and transactions...
    
    var _$observationRegistrar = Observation.ObservationRegistrar()
    
    internal nonisolated func access<Member>(
        keyPath: KeyPath<BankAccount, Member>
    ) {
        _$observationRegistrar.access(self, keyPath: keyPath)
    }
    
    internal nonisolated func withMutation<Member, MutationResult>(
        keyPath: KeyPath<BankAccount, Member>,
        _ mutation: () throws -> MutationResult
    ) rethrows -> MutationResult {
        try _$observationRegistrar.withMutation(of: self, keyPath: keyPath, mutation)
    }
}

extension BankAccount: Observation.Observable {}

// SwiftUI automatically tracks changes:
struct AccountView: View {
    var account: BankAccount
    
    var body: some View {
        // Swift tracks access to account.balance
        // View refreshes when balance changes

    }
}
```

### Exercise 1: #unwrap Macro

```swift
// สร้าง #unwrap macro ที่ unwrap optional หรือ throw error พร้อม context
// Usage: let value = #unwrap(optionalValue, "User profile") 

// Declaration:
public macro unwrap<T>(_ value: T?, _ description: String) throws -> T = 
    #externalMacro(module: "MyMacrosImplementation", type: "UnwrapMacro")

// Implementation:
public struct UnwrapMacro: ExpressionMacro {
    public static func expansion(
        of node: some FreestandingMacroExpansionSyntax,
        in context: some MacroExpansionContext
    ) throws -> ExprSyntax {
        let args = node.arguments
        guard args.count == 2,
              let valueExpr = args.first?.expression,
              let descExpr = args.last?.expression else {
            throw MacroError.missingArgument
        }
        
        return """
        {
            guard let value = \(valueExpr) else {
                throw UnwrapError.unexpectedNil(description: \(descExpr))
            }
            return value
        }()
        """
    }
}

// Support types:
public enum UnwrapError: Error, LocalizedError {
    case unexpectedNil(description: String)
    
    public var errorDescription: String? {
        switch self {
        case .unexpectedNil(let description):

        }
    }
}

    let email: String?

        let validEmail = try #unwrap(email, "User email")
        return (name: validName, email: validEmail)
    }
}
```

### Exercise 2: @Validated Macro

```swift
// สร้าง @Validated macro สำหรับ property validation
// Usage: @Validated(min: 0, max: 100) var score: Int

@attached(accessor)
public macro Validated<T: Comparable>(min: T, max: T) = 
    #externalMacro(module: "MyMacrosImplementation", type: "ValidatedMacro")

// Implementation:
public struct ValidatedMacro: AccessorMacro {
    public static func expansion(
        of node: AttributeSyntax,
        providingAccessorsOf declaration: some DeclSyntaxProtocol,
        in context: some MacroExpansionContext
    ) throws -> [AccessorDeclSyntax] {
        guard let args = node.arguments?.as(LabeledExprListSyntax.self),
              let minArg = args.first(where: { $0.label?.text == "min" })?.expression,
              let maxArg = args.first(where: { $0.label?.text == "max" })?.expression else {
            throw MacroError.missingArgument
        }
        
        guard let varDecl = declaration.as(VariableDeclSyntax.self),
              let binding = varDecl.bindings.first,
              let pattern = binding.pattern.as(IdentifierPatternSyntax.self) else {
            throw MacroError.invalidArgument("@Validated must be applied to a variable")
        }
        
        let propName = pattern.identifier.text
        let storageName = "_\(propName)"
        
        let getter: AccessorDeclSyntax = """
        get {
            return \(raw: storageName)
        }
        """
        
        let setter: AccessorDeclSyntax = """
        set {
            \(raw: storageName) = min(max(newValue, \(minArg)), \(maxArg))
        }
        """
        
        return [getter, setter]
    }
}

// การใช้งาน:
struct PlayerStats {
    @Validated(min: 0, max: 100)
    var health: Int = 100
    
    @Validated(min: 0, max: 999)
    var score: Int = 0
}

var player = PlayerStats()
player.health = 150  // Clamped to 100
player.health = -10  // Clamped to 0
print(player.health) // 0

player.score = 1000  // Clamped to 999
print(player.score)  // 999
```

### Exercise 3: @Logged Macro

```swift
// สร้าง @Logged macro ที่ log ทุก method call
@attached(peer, names: overloaded)
public macro Logged() = 
    #externalMacro(module: "MyMacrosImplementation", type: "LoggedMacro")

public struct LoggedMacro: PeerMacro {
    public static func expansion(
        of node: AttributeSyntax,
        providingPeersOf declaration: some DeclSyntaxProtocol,
        in context: some MacroExpansionContext
    ) throws -> [DeclSyntax] {
        guard let funcDecl = declaration.as(FunctionDeclSyntax.self) else {
            return []
        }
        
        let funcName = funcDecl.name.text
        let params = funcDecl.signature.parameterClause.parameters
        
        // สร้าง parameter list สำหรับ call
        let paramList = params.map { param -> String in
            let label = param.firstName.text == "_" ? "" : param.firstName.text + ": "
            let name = param.secondName?.text ?? param.firstName.text
            return "\(label)\(name)"
        }.joined(separator: ", ")
        
        // ดึง return type
        let returnType = funcDecl.signature.returnClause?.type.description ?? "Void"
        let hasReturn = returnType.trimmingCharacters(in: .whitespaces) != "Void"
        
        let loggedFunc: DeclSyntax = """
        func \(raw: funcName)_logged(\(params)) \(funcDecl.signature.returnClause ?? ReturnClauseSyntax(type: IdentifierTypeSyntax(name: .identifier("Void")))) {
            print("[\(raw: funcName)] called with: \(raw: paramList)")
            let startTime = Date()
            \(raw: hasReturn ? "let result = " : "")\(raw: funcName)(\(raw: paramList))
            let elapsed = Date().timeIntervalSince(startTime)
            print("[\(raw: funcName)] completed in \\(elapsed)s")
            \(raw: hasReturn ? "return result" : "")
        }
        """
        
        return [loggedFunc]
    }
}
```

### 20.2 Advanced @Builder Macro Implementation

```swift
import SwiftSyntax
import SwiftSyntaxMacros

public struct BuilderMacro: MemberMacro {
    public static func expansion(
        of attribute: AttributeSyntax,
        providingMembersOf declaration: some DeclGroupSyntax,
        conformingTo protocols: [TypeSyntax],
        in context: some MacroExpansionContext
    ) throws -> [DeclSyntax] {
        // ดึง type name
        let typeName: String
        if let structDecl = declaration.as(StructDeclSyntax.self) {
            typeName = structDecl.name.text
        } else if let classDecl = declaration.as(ClassDeclSyntax.self) {
            typeName = classDecl.name.text
        } else {
            throw MacroError.invalidArgument("@Builder can only be applied to structs or classes")
        }
        
        // ดึง stored properties
        let properties = declaration.memberBlock.members
            .compactMap { $0.decl.as(VariableDeclSyntax.self) }
            .filter { varDecl in
                // เฉพาะ stored properties (ไม่ใช่ computed)
                varDecl.bindings.first?.accessorBlock == nil
            }
        
        var builderMethods: [DeclSyntax] = []
        
        for property in properties {
            guard let binding = property.bindings.first,
                  let pattern = binding.pattern.as(IdentifierPatternSyntax.self),
                  let typeAnnotation = binding.typeAnnotation else {
                continue
            }
            
            let propName = pattern.identifier.text
            let propType = typeAnnotation.type.description.trimmingCharacters(in: .whitespaces)
            
            // สร้าง builder method สำหรับแต่ละ property
            let method: DeclSyntax = """
            @discardableResult
            func with\(raw: propName.capitalized)(_ value: \(raw: propType)) -> \(raw: typeName) {
                var copy = self
                copy.\(raw: propName) = value
                return copy
            }
            """
            
            builderMethods.append(method)
        }
        
        return builderMethods
    }
}

// การใช้งาน:
@Builder
struct Configuration {
    var host: String = "localhost"
    var port: Int = 8080
    var timeout: TimeInterval = 30.0
    var maxConnections: Int = 10
    var enableSSL: Bool = false
}

    .withHost("api.example.com")
    .withPort(443)
    .withTimeout(60.0)
    .withEnableSSL(true)

print(config.port)    // 443
print(config.enableSSL) // true
```

```swift
public struct AutoHashableMacro: MemberMacro, ConformanceMacro {
    
    // ConformanceMacro
    public static func expansion(
        of node: AttributeSyntax,
        providingConformancesOf declaration: some DeclGroupSyntax,
        in context: some MacroExpansionContext
    ) throws -> [(TypeSyntax, GenericWhereClauseSyntax?)] {
        return [("Hashable", nil)]
    }
    
    // MemberMacro - สร้าง hash(into:) function
    public static func expansion(
        of attribute: AttributeSyntax,
        providingMembersOf declaration: some DeclGroupSyntax,
        conformingTo protocols: [TypeSyntax],
        in context: some MacroExpansionContext
    ) throws -> [DeclSyntax] {
        let properties = declaration.memberBlock.members
            .compactMap { $0.decl.as(VariableDeclSyntax.self) }
            .compactMap { $0.bindings.first?.pattern.as(IdentifierPatternSyntax.self)?.identifier.text }
        
        let hashStatements = properties.map { prop in
            "hasher.combine(\(prop))"
        }.joined(separator: "\n        ")
        
        let hashFunc: DeclSyntax = """
        func hash(into hasher: inout Hasher) {
            \(raw: hashStatements)
        }
        """
        
        return [hashFunc]
    }
}
```
